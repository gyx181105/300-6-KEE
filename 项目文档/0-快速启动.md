### 本地开发

```bash
cd KEE

# 1. 启动数据库（pgvector 版 Postgres）
docker compose up -d db

# 编译
cargo build -p utopia-server


# 2. 启动后端（自动跑迁移，默认 :1516）
lsof -t -i:1516 | xargs kill -9 && clear &&  cargo run -p kee-server 

# 3. 启动前端（:5173，/api 代理到后端）
cd web 

lsof -t -i:5173 | xargs kill -9 && clear && pnpm dev  --port 5173
```
