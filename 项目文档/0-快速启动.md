# 快速启动

引擎已对齐 [Utopia](https://github.com/deeplethe/utopia)。推荐用上游方式启动。

## 干净库验收（推荐第一次）

完整步骤见 [4-干净库验收.md](./4-干净库验收.md)。摘要：

```bash
# 0. 打开 Docker Desktop，分支 follow-utopia
docker compose --profile app down -v
rm -rf data/files data/index data/secret.key

docker compose --profile app up -d
# 浏览器打开 http://localhost:1516 → 注册 → 管理里配模型 → 上传 → 对话
```

不要灌旧 `kee.dump`。

## Docker（预构建镜像）

```bash
docker compose --profile app up -d
```

打开 http://localhost:1516 注册。第一个账户为管理员。抽取前在「管理 → 模型」配置 chat / embedding。

## 本地开发

```bash
docker compose up -d db
cargo run -p utopia-server
cd web && pnpm install && pnpm dev
```

## 分支

```bash
git checkout follow-utopia   # 现行开发线（跟踪 upstream/main）
```

详见 [2-跟进-utopia.md](./2-跟进-utopia.md)。
